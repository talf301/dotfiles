# Rex workflow

Use the `rex-worktree` skill for new implementation work: one Rex session per worktree, one interactive agent per tab. Linear is the task tracker; Plannotator Inbox is the route for decisions and finished reviews. Firstmate inspects Rex on request. Use `first-mate` for fleet status and task handoffs.

Existing Beads data, factory scripts and detached sessions are legacy. Use them only when a task explicitly needs the old factory; keep running sessions and leases intact until they are migrated or finished. Keep the session-board timer and its Linear mirror disabled. Resource provisioning still requires human approval each time; existing compute work stays within its authorized budget.
