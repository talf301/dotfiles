# Dispatch a task

Use `rex-worktree` to find the task in Linear and start an interactive agent in the matching Rex session. A request to run work unattended still uses a visible tab. Preserve the task's required tests and independent review. The archived Beads background launcher is used only when Tal explicitly asks for the old factory.
